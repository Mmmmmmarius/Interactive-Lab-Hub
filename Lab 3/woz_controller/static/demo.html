Demo notes and event log

Text input stands in for speech. Speaking and Thinking durations set the demo pace and do not represent actual Pi latency. Each action can queue one reply, followed by silence. Automatic responses are randomly selected from 24 presets, without interpreting questions or offering help. An exchange already in progress after 20:00 can finish. New autonomous remarks wait until 10:30 the next day.
